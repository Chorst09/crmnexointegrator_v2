# Correção da busca DOU — 13/10/2026

As correções anteriores foram publicadas no nexosv2 no commit `a56d07c`, com API e frontend atualizados e healthcheck confirmando banco conectado.

A busca DOU passou a correlacionar o aviso com a contratação oficial por UASG, número, ano e modalidade. Quando a base Compras.gov está atrasada, o cadastro UASG fornece o CNPJ e a API pública do PNCP permite localizar a compra. O número do pregão não é tratado como sequencial PNCP. Associações ambíguas ou incompatíveis são rejeitadas. A publicação DOU continua como origem, com sua data e identificador preservados.

O resolvedor de documentos também funciona com avisos antigos salvos sem os identificadores PNCP: consulta a publicação completa, confirma a contratação e recupera os anexos oficiais. Os detalhes recebem os dados complementares e passam a exibir o valor recuperado e o link do processo. Links de portais citados no aviso, inclusive Petronect, são preservados. A tela distingue a publicação DOU do edital completo e identifica orçamento sigiloso.
